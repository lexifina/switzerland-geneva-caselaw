# GE Gerichte C/15281/1999

## Regeste

CONTRAT INDIVIDUEL DE TRAVAIL; RESILIATION IMMEDIATE; INTERPRETATION(SENS GENERAL); INDEMNITE(EN GENERAL); | Le texte d'un courrier mentionnant "fin de votre contrat avec effet immédiat pour faute grave" ne peut pas être compris différemment que comme valant licenciement avec effet immédiat. Peu importe que, par la suite, le salaire ait été versé durant le délai de congé. Par conséquent, une indemnité sur la base de l'art. 337c al. 3 peut être due. | CO.337; CO.18; CO.337c al. 3;

Résumé
:
Le texte d'un courrier mentionnant "fin de votre contrat avec effet immédiat pour faute grave" ne peut pas être compris différemment que comme valant licenciement avec effet immédiat. Peu importe que, par la suite, le salaire ait été versé durant le délai de congé. Par conséquent, une indemnité sur la base de l'art. 337c al. 3 peut être due.
