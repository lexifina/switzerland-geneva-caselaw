# GE Gerichte C/10828/1999

## Regeste

CONTRAT INDIVIDUEL DE TRAVAIL; TRAVAIL SUR APPEL; SALAIRE; CALCUL; DELAI DE RESILIATION; | Le travail sur appel est admissible, pour autant que les dispositions légales impératives soient respectées. Durant le délai de congé, le salaire doit être calculé sur la moyenne des rémunérations perçues pendant une période déterminée équitablement. | CO.322;
