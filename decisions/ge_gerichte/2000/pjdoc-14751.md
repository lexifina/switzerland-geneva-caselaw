# GE Gerichte [pjdoc 14751]

## Regeste

Résumé:
 Le travail sur appel est admissible, pour autant que les dispositions légales impératives soient respectées. Durant le délai de congé, le salaire doit être calculé sur la moyenne des rémunérations perçues pendant une période déterminée équitablement.
