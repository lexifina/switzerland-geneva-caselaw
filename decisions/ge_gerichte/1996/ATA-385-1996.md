# GE Gerichte ATA/385/1996

## Regeste

Résumé:
 On ne peut inférer, du fait que le Tribunal ignorait l'existence d'une base légale susceptible de modifier son point de vue sur le dossier, qu'il serait parvenu à une solution différente de celle retenue, dès lors que ladite base légale n'entrait pas dans le cadre des dispositions applicables pour trancher le litige.
